## 4. How the main thing works

Issuing a token, as the code does it now:

1. The caller presents an API key to `POST /v1/token`.
2. The key is looked up and its scopes read.
3. `api/auth/signing.py` signs a JWT with the staging private key, `exp` 15
   minutes out, and stamps the `kid`.
4. The SDK fetches `/v1/jwks` once, caches by `kid`, and verifies offline.
