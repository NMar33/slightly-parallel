## L2
Write a task onto the Slightly Parallel board from the conversation, the way the operator would type it themselves: #task for later (the agent column), #now for the task this chat starts on (doing), #now-todo and the like for the operator's message filed in a column; a #now task's text is the operator's message, the agent writes the title. Use only when the operator types one of them.
