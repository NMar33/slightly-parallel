## L2
Keep the program's cores for Slightly Parallel: #core-new makes a core from the operator's message (a short name, a type, the files you know), #core-note adds the message as a note with your one line, #core attaches the message and this chat's task, #core-off removes one from view after the operator confirms; and the one-line auto note when finished work changes a tracked core. Use when the operator types one of them or the hook's notice names tracked cores.
