## L2 — Elaboration

SDK generator will emit TS + Python clients, but most infra teams reach for curl. A thin CLI (~500 LOC) over the Python SDK unlocks shell scripting, CI recipes, dry-run mode, JSON pretty-print — and makes the product demo-able in a terminal.

## L3 — Implications / Next steps

- Pick framework: click vs typer (typer wins on docs)
- Auto-generate subcommands from OpenAPI paths
- Publish to PyPI as `alpha` — grab the name early

## L4 — Raw context

Every competitor ships a CLI. Not having one shows up in eval checklists. Cheap to build once SDK generator lands (g_a4).
