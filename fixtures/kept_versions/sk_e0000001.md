---
name: before-you-say-done
description: Run the project's checks and report what they printed, before saying a task is done. Use when finishing any task.
---

1. Run the tests.
2. Run the type check.
3. If anything failed, fix it, or say what failed and stop.
4. Report the task with the output, not from memory.

Check: the last command printed no errors.
