## L2 — Problem context

The v0 hand-written SDK still ships in prod and its request models differ from the v1 OpenAPI spec (nullable fields, enum values). SDK users get 422s they do not expect. No error handler bridges these — SDK generator work (g_a4) will fix it, but until then it's noise.

## L3 — Attempts / workarounds

- Add regression matrix — v0 SDK against v1 endpoints
- Ship a 'compat mode' shim on the server side for 90 days
- Fold into the SDK generator sprint (g_a4)

## L4 — Resolution / raw discussion

Two support tickets this week traced to this. Low blast radius (<1% of traffic uses v0 SDK) but annoying to triage.
