# Точки входа: спецификация сборки для помощников

План для трёх помощников (бэкенд, MCP, страница) по решению dc_4e0a9b12: вариант A с полками. Задача tk_51b87348. Каждый помощник читает этот план целиком, свой раздел и раздел «Правила для всех».

```mermaid
flowchart LR
  M[Сообщение с тегом] --> H[Хук capture.py]
  H --> Q[Вопрос агенту: список тем]
  Q --> O[Ответ оператора: номера]
  O --> W[entrypoint_offer и entrypoint_way]
  W --> S[(entrypoints.csv)]
  S --> R[/api/entrypoints/desk]
  R --> P[Страница Точки входа]
```

## 1. Поля записи

| Поле | Тип | Кто пишет | Заметка |
| --- | --- | --- | --- |
| id | ep_ + 8 hex | сервер | неизменен |
| project | код проекта | сервер | из чата |
| name | строка | оператор | пусто, пока не задано |
| title | строка | агент | первая строка сообщения |
| state | active, paused, dead | оператор | по умолчанию active |
| what | markdown | агент | без лимита слов с d4ecd115 |
| ways | список | агент, оператор | страница, сайт, файл, папка, скрипт |
| stops | список | агент при завершении | последние пять в брифинге |

## 2. Маршруты

| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | /api/entrypoints/desk | темы с путями, снимками, остановками |
| GET | /api/entrypoints/{id}/briefing | текст для агента целиком |
| POST | /api/entrypoints/{id}/way | путь входа, 201 |
| POST | /api/entrypoints/{id}/stop | остановка оператора |
| GET | /api/entrypoints/ports | проверка портов, 2 с на порт |

## 3. Помощник: бэкенд

:::fold Подробно
- `entrypointlib.py`: чтение и запись, версии записи в `entrypoint_details/{id}/v{n}.md`.
- Порт проверяется соединением, не HTTP: страница Vite отвечает не сразу.
- Брифинг собирается на сервере, страница его только показывает.
- Тесты: `test_entrypoint_routes.py`, `test_entrypoint_versions.py`; каждый маршрут с отказом 404 и 422.
:::

## 4. Помощник: MCP

:::fold Подробно
- Четыре инструмента: entrypoint_offer, entrypoint_way, entrypoint_shot, entrypoint_stop.
- Инструмент отказывает без захваченного чата, текст отказа говорит, что делать.
- Контракт `prompts/contract/56-entrypoint.md`: когда писать, что в записи, пример ответа со списком.
:::

## 5. Помощник: страница

:::fold Подробно
- `features/entrypoints/desk`: Desk, parts, faces, context. Список слева 240, карточка справа.
- Переключатель полки и список хранится в браузере, `?layout=` в адресе главнее.
- Русские строки в `i18n/ru/entrypoints.json`, оба темы, телефон.
:::

## Правила для всех

```copy Правила для помощников
Ты помощник в круге сборки точек входа, задача tk_51b87348.
1. Работай только в своих файлах: бэкенд — backend/, MCP — backend/backend/mcp.py и prompts/contract, страница — frontend/src/features/entrypoints.
2. git add по одному пути, никогда -A. Чужие незакоммиченные файлы не трогай.
3. Перед словом «готово» прогони тесты и назови число: pytest -q, vitest, playwright.
4. Сообщение коммита — обычными предложениями, в конце Task и Agent.
5. Не пушь.
```
