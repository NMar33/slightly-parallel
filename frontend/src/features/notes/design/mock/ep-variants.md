## Что видно

A читается лучше всех: брифинг виден без клика, список короткий. B красивее и лучше для возврата через месяц: снимок узнаётся быстрее имени. C показывает, где что двигалось, но тема, которую не трогали неделю, теряется. D полезна, только если тем больше двадцати. E хороша на телефоне и плоха на большом экране. F — для проверки портов, не для чтения.

```choice Какой вариант берём в работу?

3. A и C вместе: лента над карточкой
4. Ни один, нужен ещё круг
```

```choice Где показывать проверку портов?

```

## Замечания к снимкам

- На B подписи плиток обрезаются на русском при ширине меньше 220: нужен перенос.
- На D колонка «мёртвые» пустая на демо-данных, пустое состояние не нарисовано.
- На всех вариантах команда запуска не помещается в строку: копировать её целиком.
