# Usage: откуда берутся лимиты плана

Лимиты плана Claude Code страница Usage берёт только из строки состояния: другого источника нет, API их не отдаёт. Строка состояния пишет проценты окна 5 часов и недели в файл раз в ответ; сервер читает последний.

Поэтому лимиты видны, только пока открыт хоть один чат Claude Code. Codex лимитов не пишет, у него только токены. Решение dc_7f2c0a18: не угадывать лимиты из токенов, показывать «нет данных».

# Harbor Lights: сообщение агенту монтажа о нарезке Shorts

Для чата монтажа в проекте 2603-harbor-lights-video. Нарезка трёх Shorts из выпуска 04, каждая до 50 секунд.

```copy Сообщение агенту монтажа
Нарежь из выпуска 04 три Shorts по 40–50 секунд: 01:05–01:52, 04:20–05:08, 07:40–08:26. Вертикаль 1080x1920, ведущий по центру, субтитры крупно снизу, без музыки. Файлы положи в export/shorts/04-a.mp4, 04-b.mp4, 04-c.mp4 и ответь списком с длительностью.
```

После ответа посмотреть все три на телефоне.

# Тур: экспорт GIF и MP4, отчёт

Отчёт помощника по экспорту тура. Запись идёт кадрами через скриншоты страницы, а не MediaRecorder: он терял кадры на swiftshader. GIF собирается gifenc, MP4 — mp4-muxer.

| Формат | 30 с тура | Размер | Время сборки |
| --- | --- | --- | --- |
| GIF 960 | 300 кадров | 7,8 МБ | 41 с |
| MP4 1440 | 900 кадров | 2,1 МБ | 26 с |

Коммиты 5d0c2e1 и a7f93b0. Осталось: после npm install перезапускать Vite песочницы, иначе тур пишет пустые кадры.
