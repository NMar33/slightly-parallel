# Tidepool: перенести ручной навигатор в точки входа

Сообщение для агента проекта 2512-tidepool-app. Навигатор `agents/tidepool-nav.md` агенты Tidepool ведут руками с лета: темы, ссылки, команды запуска, где остановились. Теперь это делают точки входа Slightly Parallel (ep_7a31c0de), и навигатор надо перенести в них, а файл оставить ссылкой. Задача tk_9b20e4f1.

## Что сделать

1. Открыть чат с агентом в папке `2512-tidepool-app` (последний был cc-b71e0f34).
2. Вставить сообщение ниже целиком, ничего не добавляя: в нём уже есть команды и порядок.
3. Когда агент ответит списком тем, выбрать номера (обычно все) и ответить им.
4. Отметить ниже, что перенос прошёл, и посмотреть страницу Точки входа.

```copy Сообщение агенту Tidepool
Перенеси ручной навигатор agents/tidepool-nav.md в точки входа Slightly Parallel.

1. Прочитай навигатор целиком. Каждый его раздел верхнего уровня — кандидат в тему.
2. Покажи мне нумерованный список тем: имя, что открывать (страница, сайт, файл), команда запуска и папка, порт. Ничего не записывай, пока я не выберу номера.
3. Для выбранных тем вызови entrypoint_offer, затем entrypoint_way на каждый путь входа. Где остановились, бери из последних строк раздела.
4. Скриншоты: для тем с локальной страницей сними по одному через entrypoint_shot.
5. В самом навигаторе оставь одну строку: «Перенесено в точки входа Slightly Parallel 2026-11-16, темы: …». Остальное удали, это в git.
6. Закоммить навигатор отдельным коммитом и ответь списком тем с их ep_.
```

## Проверка после ответа

- [ ] Агент показал список и ждал выбора
- [ ] Темы появились на странице Точки входа с путями входа
- [ ] У страниц есть скриншот и команда запуска
- [ ] В навигаторе осталась одна строка, коммит есть

:::fold Почему не скриптом
Навигатор написан свободным текстом: разделы разной формы, команды встречаются в прозе, порты указаны не везде. Скрипт угадает половину, агент проекта знает, что из этого ещё живо. Поэтому перенос делает он, а Slightly Parallel только принимает записи через MCP.
:::
